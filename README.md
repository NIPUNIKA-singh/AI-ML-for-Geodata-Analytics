# AI-ML-for-Geodata-Analytics
IIRS Outreach Programme on "AI/ML for Geodata Analytics", conducted by the Indian Institute of Remote Sensing (IIRS), ISRO. The course covers topics including GIS data analytics, image processing, vector data processing, spatial data science, machine learning, deep learning, GeoAI and Generative AI for geospatial applications.

Learning never stops, and I'm looking forward to gaining new perspectives, building practical knowledge, and exploring how AI can solve real-world geospatial challenges.
